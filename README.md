## About Me

I'm a **Laravel & Flutter Developer** focused on building complete business solutions.

I work on projects that combine backend systems, e-commerce, APIs, dashboards, and mobile applications into one reliable product.

My approach is simple:

> **Understand the business → design the system → build the product → deploy and improve it.**

Most of my commercial projects are private because they contain client-owned code and business data.
For that reason, I share selected work through **public case studies** without exposing private source code.
